# Design System — IR 强化的 3DGS 全链路重建系统

> **设计立场**
> 这不是一块"看板"，而是一台**测量仪器**的控制台。
> 因此一切视觉决策都服从同一条直觉——*克制、精确、可读*：
> 扁平白底、靠留白而非描边分隔；线条要细、阴影要近乎消失；
> 数值用等宽字体像仪表读数一样对齐；动效只用于"反馈"，不用于"装饰"。
> 任何让界面变"重"、变"花"、变"挤"的改动，默认都是错的。

本文档记录该界面的**视觉规范、组件规则、响应式策略**，以及迭代过程中**踩过的坑与对应解法**，供后续功能开发与重构对齐使用。

## 1. 适用范围与运行环境

- 界面运行于 **CEF（Chromium Embedded Framework）内嵌窗口**，不是独立浏览器页面。
- 这一前提直接决定了外壳约束（见 §2 与 §10 第 1、2 条），**所有布局假设都必须建立在"无浏览器外壳、无系统标题栏可依赖"之上**。
- 目标 DPI 覆盖 **1x / 1.25x / 1.5x / 2x**；2x 下截图视觉上等同放大，规范必须保证各倍率下三栏不变形。
- 多文件交付：`index.html` + `styles/` + `scripts/` + `viewer/`，**无构建步骤**；由宿主经自定义协议 **`app://localhost`** 托管（不是 `file://`，否则 ES Module 无法加载）。字体使用**系统本地字体**（无 Google Fonts / 网络依赖），外部仅依赖 CDN（Babylon.js）等。

## 2. 设计哲学

| 关键词 | 含义                                | 反例（禁止）               |
| ------ | ----------------------------------- | -------------------------- |
| **素** | 白底 + 极淡描边，靠留白分区         | 重阴影浮起卡片、深色块堆叠 |
| **轻** | 描边 1px 且色淡，阴影近零           | 粗边框、强投影、高饱和填充 |
| **细** | 轨道线、滑块轨、进度条一律细线      | 9px 粗轨道、4px 滑块轨     |
| **准** | 数值等宽、对齐、tabular-nums        | 比例字体显示时间码导致跳动 |
| **活** | 动效仅做反馈（hover / 状态 / 录制） | 装饰性循环动画、无意义弹跳 |

**核心戒律**：当一处改动让界面"更醒目"时，先问是否其实让它"更吵"。仪器感来自**减法**。

## 3. 色彩系统

### 3.1 语义色（CSS 变量，复制即用）

```css
:root{
  /* 文本 */
  --ink:      #1d2433;   /* 主文本 / 标题 */
  --ink-2:    #5a6478;   /* 次文本 / 标签 */
  --ink-3:    #9aa3b4;   /* 弱化文本 / 占位 / 小标 */

  /* 表面 */
  --panel:    #ffffff;   /* 卡片底 */
  --panel-2:  #f7f9fc;   /* 内嵌块底（设备行/读数/按钮未激活） */

  /* 线条 —— 注意"淡"，这是仪器感的关键 */
  --line:      #edf0f5;  /* 顶/底栏分隔线 */
  --line-2:    #f0f2f7;  /* 内嵌块描边 */
  --card-line: #eceff4;  /* 卡片描边 */

  /* 品牌 / 状态 */
  --blue:      #2563eb;  /* 主色：选中、轨迹、相机标记、滑块填充 */
  --blue-soft: #eaf1ff;  /* 选中态浅底 */
  --blue-ink:  #1d4ed8;  /* 选中态文字 */
  --green:     #16a34a;  /* 连接正常 */
  --green-soft:#dcfce7;  /* 状态点光晕 */
  --red:       #e23b3b;  /* 录制 / 危险 */
  --red-soft:  #fde8e8;  /* 停止可用态浅底 */
}
```

### 3.2 应用背景（环境光）

```css
background:
  radial-gradient(1200px 520px at 80% -12%, rgba(37,99,235,.045), transparent 60%),
  linear-gradient(180deg, #fcfdff, #f4f6fb);
```
> 仅 4.5% 透明度的蓝做"环境光"，**禁止**改成 aurora 色斑 / 多色渐变 / 高饱和 blob。

### 3.3 用色守则

- 主色 `--blue` 只用于**有意义的状态**：选中、活动轨迹、相机、滑块进度、主操作激活。**不要**用蓝色给标题加竖条装饰（见 §10 第 9 条）。
- 红色仅录制与危险删除 hover；绿色仅连接状态。
- 文本层级严格三级（ink / ink-2 / ink-3），**不要**自创第四级灰。

## 4. 字体系统

### 4.1 字体栈

```css
--font-ui:   "PingFang SC","Microsoft YaHei","Hiragino Sans GB","Segoe UI",system-ui,sans-serif;
--font-mono: "Cascadia Code","Consolas","SF Mono",ui-monospace,"Microsoft YaHei",monospace;
```

- **UI 字体**：系统本地字体（Windows：Microsoft YaHei + Segoe UI；macOS：PingFang SC）。不再依赖 Google Fonts，离线可用。
- **等宽字体**：系统本地等宽字体（Windows：Cascadia Code / Consolas），**强制**用于一切"读数"——高度/角度/坐标、时间码、帧数、COM 口、分辨率、存储路径、快捷键字母。

### 4.2 字号 / 字重层级

| 角色                    | 字号                | 字重      | 字体     | 备注                     |
| ----------------------- | ------------------- | --------- | -------- | ------------------------ |
| 品牌标题                | 13.5                | 700       | ui       | 顶栏左                   |
| 卡片标题                | 13                  | 700       | ui       | **无前置蓝条**           |
| Tab（激活/默认）        | 12.5                | 600 / 500 | ui       | 激活蓝 + 下划线          |
| 设备名 / 轨迹名         | 12 / 11.5           | 600       | ui       | 单行省略                 |
| 规格 / 帧数行           | 10                  | 400       | **mono** | 单行省略                 |
| 读数数值                | clamp(11,1.05vw,13) | 600       | **mono** | `overflow-wrap:anywhere` |
| 时间码 / 坐标           | 10.5–11.5           | 600       | **mono** | `tabular-nums`           |
| 状态"连接"              | 11                  | 700       | ui       | 绿                       |
| 小标（高度/角度 label） | 9.5                 | 400       | ui       | ink-3                    |

> **守则**：数值字重停在 **600**，不要 700/800——过粗会破坏仪表的"细读"感。

## 5. 间距 · 圆角 · 阴影 · 描边

```css
--pad: clamp(9px, .9vw, 14px);   /* 卡片内边距 */
--gap: clamp(8px, .75vw, 12px);  /* 栅格/卡片间距 */
--r:   8px;   /* 卡片圆角 */
--r-sm:6px;   /* 内嵌块/按钮圆角 */
--shadow:      0 1px 2px rgba(20,30,55,.03);          /* 静默 */
--shadow-hover:0 4px 14px rgba(20,30,55,.06);         /* 仅 hover 微抬 */
```

- 圆角**两档**（8 / 6），**禁止** round-2xl 式大圆角。
- 阴影**静默态近零**，只在 hover 出现极弱抬升——靠"描边 + 留白"分区，不靠投影。
- 描边统一 1px；卡片用 `--card-line`，内嵌块用 `--line-2`。

## 6. 布局系统

### 6.1 外壳栅格

```css
.app{ width:100vw; height:100vh; display:grid; grid-template-rows:auto minmax(0,1fr) auto; }
```
三行 = 顶栏 / 工作区 / 状态栏。工作区行用 `minmax(0,1fr)` 是关键（见 §10 第 5 条）。

### 6.2 三栏 = 比例列，非固定像素

```css
.workspace{ grid-template-columns: minmax(0,18fr) minmax(0,56fr) minmax(0,23fr); }
```
- **必须**用 `fr` 比例 + `minmax(0,…)`，**禁止**回退到固定 `px` 列宽（固定 px 是滚动条与堆叠错乱的根因，见 §10 第 3、4 条）。
- 比例含义：左控制 18 / 中预览+轨道 56 / 右轨迹 23。

### 6.3 垂直不溢出链路（弹性吸收余量）

每一列 `.col` 是纵向 flex；其中**可伸缩**的卡片用 `.stretch{ flex:1 1 auto; min-height:0 }`，其内部可滚动区（轨迹列表、3D 视口）同样 `flex:1 + min-height:0`。
> `min-height:0` 是 flex/grid 子项能"收缩到比内容更小"的开关，**整条链路缺一环就会溢出**（§10 第 6 条）。

### 6.4 断点策略

| 断点    | 行为                            |
| ------- | ------------------------------- |
| `>1366` | 标准密度                        |
| `≤1366` | 收紧 padding/gap，设备图标 28px |
| `≤820`  | **才**堆叠为单栏                |

> **铁律**：中等宽度（820–1366）**必须保持三栏**，只调密度，不堆叠。把堆叠断点设高是历史 bug 根因（§10 第 4 条）。

## 7. 组件规范

### 7.1 卡片与标题
- 标题为**纯加粗黑字**，**无**前置蓝色竖条、无图标装饰。
- 卡片 hover 仅 `--shadow-hover`，不做位移/缩放。

### 7.2 设备行
- 结构：`图标(30×30) + meta(名+规格) + 状态文字`。
- 名称、规格**均** `white-space:nowrap; overflow:hidden; text-overflow:ellipsis`，并加 `title` 悬停看全名。
- 状态**始终**显示绿色文字"连接"，**不要**在窄屏把它收成圆点（曾尝试，与设计稿不符，已废弃）。
- 相机规格为**真实枚举数据**：预览启动后经 `track.getSettings()` 取实际分辨率/帧率，`enumerateDevices()` 取真实设备名，写入 `meta small`（长名省略，`title` 全文）。电机行显示真实串口与波特率（`COMx · <baud> baud`），未连接时显示"未连接"。

### 7.3 滑块
- 轨道 **3px**，圆头 thumb **13px** 白底蓝边。
- 填充用 `linear-gradient` + `--p` 变量在 `input` 事件里实时刷新。

### 7.4 实时预览
- 双图 `1fr 1fr`，单图 `aspect-ratio:16/10`，`max-height:clamp(140px,27vh,300px)` 封顶。
- 标签（RGB 预览 / IR 预览）为**无底白字 + 文字投影**，**不是**深色胶囊。
- 右上角工具按钮半透明黑底，hover 转蓝。
- **双摄录制**：预览区下方一行「录制视频」红色按钮（呼吸动画），**与轨迹录制相互独立**——点它只录双摄视频。RGB / IR 两路经浏览器 `MediaRecorder` **同一事件循环内先后 `start()`**，停止时同步 `stop()` 并**分别**保存本地（`capture_rgb_<时间戳>.mp4|webm` / `capture_ir_…`）。录制中每路预览右下角显示红色 REC 徽标（闪烁圆点 + 等宽时间码）。未连接相机时点击给出提示，不报视频错误。

### 7.5 轨道与运动状态（SVG，最易出错，重点）
画布与容器**比例严格一致**：

```
.stage  → aspect-ratio:15/7; max-width:940px; justify/align-self:center
<svg>   → viewBox="0 25 450 210"  preserveAspectRatio="xMidYMid meet"
```
元素线宽与构成（**对齐设计稿**）：
- 轨道环：`stroke #e2e7ef`，**3.5px** 细线（曾误用 9px）。
- 运动轨迹：**只画下半圈一段弧**（角度 `195°→345°`），`#2563eb` 2px `dash 6 6`，左端带方向箭头。**禁止**画整圈虚线。
- 采样位姿弧：`#7aa2f7` 5px 圆头短线，按设计稿点位排布。
- **顶部取景相机**（常亮）：圆角蓝框 + 镜头 + 三条光芒线 + 一条垂直虚线指向物体。
- **轨道相机标记**（随角度/回放移动）：圆角蓝框 + 镜头，**正下方带一个蓝色实心点**。
- 背景：**纯白冷调径向渐变，无网格**（曾误加 22px 网格，已删）。
- 目标物体：石狮子**直接立于圆台**，带接触阴影，**无**虚线贴图框；圆台色调偏浅。
- 视角下拉（透视/正视/俯视）通过改变椭圆 `ry` 实现，`meet` 保证椭圆**几何永不变形**。
- 上下/左右运动读数（方向箭头 + `PWM`/`RPM`）以**半透明白底浮层**覆盖在舞台左下角（绝对定位，不占轨道布局空间）；**图例已删除**，颜色语义不再需要文字解释。

### 7.6 录制控制
- **恒为 5 列一行**：`1.3fr 1fr 1fr 1fr 1fr`（开始 / 停止 / 时长 / 帧数 / 预计帧数）。
- **禁止**在中间断点改成 4 列（会导致"预计帧数"掉到第二行，与设计稿不符）。
- 按钮文字窄时允许 `line-height:1.2` 折两行兜底，但不掉格。
- 轨迹录制（开始/停止/Space）与双摄视频录制（预览区「录制视频」按钮）**相互独立**：可分别启停，也可同时进行。

### 7.7 轨迹管理
- 选中项：`--blue-soft` 底 + 蓝描边 + 内阴影环。
- 操作四键：新建 / 重命名 / 删除 / **导出（向上箭头 + 托盘）**——导出图标方向**朝上**，不是下载朝下。
- 进度条 **4px**，knob **11px**。

### 7.8 提示区（两种快捷键呈现，勿混）
- **左栏"快捷键说明"**：对照表，键名用**带框 `kbd`**。
- **右栏"提示"叙述句**：键名用**无框等宽加粗** `.hk`（`font-mono; font-weight:600`）。
> 设计稿两处用法不同，**不要**统一成一种。

## 8. 交互与动效

动效只服务反馈，时长 100–400ms，缓动 `ease` / `cubic-bezier(.2,.7,.2,1)`。

| 元素                         | 反馈                                            |
| ---------------------------- | ----------------------------------------------- |
| 设备行 / 按钮 / 轨迹项 hover | 描边变蓝 + 背景转白 + `translateX/Y` 1–2px      |
| 按钮 active                  | `scale(.94–.97)`                                |
| 连接状态点                   | 外环 `pulse` 1.8s                               |
| 录制中                       | 按钮 `breathe` 阴影呼吸 + 圆点变方并 `blink`    |
| Tab 切换                     | 下划线 `scaleX` 滑入 .25s                       |
| 卡片入场                     | `rise` 位移淡入，按列 stagger（delay .02–.14s） |
| 轨迹虚线                     | `stroke-dashoffset` 持续流动                    |
| 操作反馈                     | 底部居中 `toast`（淡入 + 1.9s 后淡出）          |

**快捷键**：`W/A/S/D` 运动（按住连续，受速度滑块影响）、`Space` 录制开关、`P` 播放/暂停、`R` 重置。焦点在 `input/select` 时不拦截。

## 9. 响应式与缩放防变形

防变形的三道闸：

1. **比例列**（§6.2）让宽度收缩时三栏等比变窄，而非某栏先崩。
2. **`clamp()` 密度**让 padding/字号/读数随视口平滑缩放，避免硬切。
3. **省略号 + `min-height:0` + 比例封顶**让内容在变窄/变矮时"截断或吸收"，而非"撑破或堆叠"。

3D 视口单独保障：容器固定 `15/7` 比例 + `viewBox` 同比例 + `meet`，使椭圆在任意宽高下**只缩放、不拉伸**；宽/中屏几乎贴边，仅极矮视口被 `max-height` 截高时留少量白边（可接受）。

## 10. 踩坑记录与注意事项

> 本节是迭代中真实出现的问题汇编，**每条都给出根因与守则**，是后续开发最该先读的部分。

| #    | 现象                                                         | 根因                                            | 解法                                                         | 守则                                        |
| ---- | ------------------------------------------------------------ | ----------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------- |
| 1    | 顶部出现两套标题栏（HTML 画的 `— □ ×` 与 CEF 外壳重复）      | 误把"假窗口 chrome"画进页面                     | 删除整行 window chrome，仅保留 Tab 行；`设置`齿轮挪到 Tab 行右侧 | **CEF 内不要画系统标题栏/关闭按钮**         |
| 2    | 嵌入后四周露灰边 / 圆角缺口                                  | `.app` 带了外圆角与外边距、外阴影               | `.app` 改 `100vw×100vh` 直角铺满，去外阴影/外边距            | 外壳**直角铺满**，圆角只用在内部卡片        |
| 3    | 三栏都出滚动条，组件过大                                     | 列宽用固定 px，内容超高无吸收                   | 列宽改 `fr` 比例；可伸缩卡 `flex:1+min-height:0`；预览/读数用 `aspect-ratio+max-height` 封顶 | 列宽**禁固定 px**；垂直靠弹性吸收           |
| 4    | 中等宽度就错乱堆叠，3D 浮层盖住控件                          | 堆叠断点设太高；旧 3D 用绝对定位/固定尺寸       | 堆叠断点降到 `≤820`；3D 改为正常流内自适应 SVG               | 中等宽度**保三栏**；3D **禁绝对定位**       |
| 5    | 矮屏整栏滚动 / 卡片被顶出                                    | 工作区行未设 `minmax(0,1fr)`，grid 行被内容撑高 | 工作区行 `minmax(0,1fr)`                                     | grid 可滚动行**必须** `minmax(0,…)`         |
| 6    | 中栏卡片互相重叠                                             | flex 链路某环缺 `min-height:0`，子项无法收缩    | `orbit-body / stage / col` 全链路补 `min-height:0`；stage `align-self:center` 居中吸收余量 | flex 收缩链路**一环都不能少**               |
| 7    | 左栏设备名竖排成 5–6 行（"RGB／相机"）                       | 名称/规格未限制换行                             | `white-space:nowrap + ellipsis + title`                      | 列表项文本**默认单行省略**                  |
| 8    | "当前位置 45.0°/120mm" 换行撑高读数块                        | 长串无折行控制                                  | `overflow-wrap:anywhere; word-break:break-word` + 列宽 `clamp` | 读数块**允许整词折行但不溢出**              |
| 9    | 与设计稿不符：标题多蓝条、卡片太重、轨道 9px 粗线、虚线画整圈、缺顶部取景相机、缺相机下蓝点、stage 有网格、石狮子带虚线框、预览标签是胶囊、导出图标朝下、录制掉行、提示带框 | 早期"加重视觉"的惯性，未逐像素对照设计稿        | 逐项削薄/补齐（见 §7 各条）                                  | **先对照设计稿做减法**，再考虑加法          |
| 10   | 2x DPI 下看着像整体放大、挤压                                | 用绝对尺寸而非比例                              | 全面 `比例列 + clamp + 省略号`，1x–2x 均稳                   | 尺寸**优先相对/clamp**                      |
| 11   | 想再调大椭圆却破坏比例                                       | 改 `viewBox` 未同步改容器比例                   | 调 `.stage max-width`（如 940→1080）即可，比例自动跟随；**不要**单改 viewBox 或单改 ry | 椭圆大小调**容器**，几何调** ry**，二者别混 |

**额外注意**
- `preserveAspectRatio` 用 `meet` 保不变形；若误用 `none` 椭圆会被拉成怪形。
- 半弧虚线用 `<path d=…>` 由 `arcPath(195,345)` 生成，**不要**用整 `<ellipse>` + dash（那是整圈）。
- 顶栏/状态栏用半透明白 + `backdrop-filter:blur`，但**不要**全站 glassmorphism。

## 11. 离线兜底与可访问性

- 预览图与中心物体图均挂 `onerror`：加载失败时父级加 `.broken` 显示占位块，物体图回退到 `#objFallback` 文字块——**保证离线/断网不破图**。
- 所有图标按钮带 `title`；设备行带 `title` 全文。
- 文本对比度：主文本 `#1d2433` 于白底充足；弱化文本 `#9aa3b4` 仅用于非关键 label，不承载关键信息。
- 状态不仅靠颜色：连接除绿点外仍有"连接"文字；选中除蓝底外仍有描边环。

## 12. Do / Don't 速查

**Do**
- 用比例列 + `minmax(0,…)` + `min-height:0` 链路。
- 数值一律等宽字体 + `tabular-nums`。
- 描边淡、阴影近零、圆角小。
- 动效只做反馈。
- 改动前先逐像素对照设计稿。

**Don't**
- 画 CEF 假窗口栏 / 外层圆角。
- 固定 px 列宽 / 高堆叠断点。
- 给标题加蓝条 / 给卡片加重阴影。
- 轨道画粗线 / 虚线画整圈 / 加网格背景 / 给物体加虚线框。
- 预览标签用胶囊 / 导出图标朝下 / 录制控制中间断点掉行。
- 用渐变标题、aurora 色斑、全站毛玻璃、大圆角。

## 13. 版本演进摘要

- **v1**：搭起三栏与全部交互，但组件过大、三栏滚动、外层带圆角与假窗口栏。→ 确立"比例列 + 弹性吸收 + 直角铺满 + 删 chrome"。
- **v2**：修滚动与堆叠，但暴露设备名竖排、读数撑高、3D 留白/变形、卡片重叠。→ 确立"单行省略 + overflow-wrap + 3D 比例匹配(meet) + min-height:0 全链路"。
- **v3（当前）**：逐像素对齐设计稿——去蓝条、削卡片、细轨道、半弧虚线、补顶部取景相机与相机下蓝点、去网格、实物立姿、无底预览标签、导出朝上、录制恒 5 列、提示无框键名。→ 确立"仪器感减法"为最高原则。
- **v3.1**：实时预览区新增**双摄视频录制**（浏览器 `MediaRecorder` 同步启停 + 分别保存本地），**与轨迹录制相互独立**可同时进行；设备行改用**真实枚举数据**（相机名称/分辨率/帧率，电机真实串口与波特率）；运动读数（上下/左右 + PWM/RPM）移入轨道舞台左下角浮层、**删除图例**，压缩轨道与运动状态模块，为预览录制控制腾出纵向空间。
- **v3.2**：重建预处理系统「输入设置」新增**输入模式**（`#inputMode`）：「上下融合视频」（单文件→切分为 rgb.mp4/ir.mp4，默认）与「独立视频」（分别选择 RGB/IR 视频文件，跳过切分，直接对两路视频抽帧）；「处理进度」卡片**删除百分比进度条**（`.progress-bar` / `#progressFill` / `#progressPct`），改为等宽文本 `#progressLabel` 显示「正在执行 xxx ...」，随步骤更新（`setProgress` 移除，改由 `setProgressLabel()` 驱动）。
- **v3.3**：新增**设置窗口**（`styles/components/settings.css` + `scripts/components/settings.js`）——点击顶栏「设置」按钮弹出（替换原 `chrome://settings`），圆角弹窗、**左侧导航 + 右侧内容**布局，包含三页：
  - **基础设置**：默认输出目录（`outdir`）与默认图像目录（`outdir/imgs`），保存到 `localStorage`（键 `app_settings`），启动时自动回填主界面 `outputDir` / `imageDir`（仅当为空）。
  - **调试设置**：CEF 传参调试（输入请求字符串，可选自动 Base64 编码字符串参数）、打开 DevTools（`sendRequest('devTools')`，无参、成功返回 `Success`）、打开 Chrome 设置（`sendRequest('chromeSettings')`，无参、成功返回 `Success`）、重载页面、清空页面数据。
  - **关于**：软件介绍、软件版本、CEF 内核版本（取 User-Agent 中 Chrome 号）、运行环境、程序目录、User-Agent（点击复制）。
